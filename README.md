# YouTube Playlist Search Extension

This Chrome extension adds a search functionality to YouTube playlists, allowing you to search for videos within a playlist by title or channel name.

## Installation

1. Download or clone this repository to your local machine
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the folder containing the extension files
5. The extension will be installed and ready to use

## Usage

1. Go to any YouTube playlist page
2. You'll see a new search box appear below the playlist header
3. Type your search term in the input field
4. The playlist will be filtered in real-time to show only matching videos
5. The number of matching videos will be displayed below the search box

## Features

- Real-time search filtering
- Search by video title or channel name
- Matches are case-insensitive
- Search results count
- Works with YouTube's dark mode
- Automatically appears only on playlist pages

## Note

You'll need to create icon files (icon48.png and icon128.png) for the extension or modify the manifest.json to remove the icons section.
